Privacy notice (English)

  • Only bookmarks inside folders you explicitly connect are synced (titles, URLs, folder structure).
  • The server (the Supabase project operator) can read this data. No end-to-end encryption or zero-knowledge.
  • No analytics, ads, external favicon requests, browsing-history collection or link checking. The server never opens bookmark URLs.
  • Change logs and trash contents are kept on the server for 30 days. IDs and deletion state of deleted items remain while the account exists.
  • Account deletion (Settings, bottom) deletes server data; bookmarks in the browser remain.
  • Operator, storage region and contact for the official hosting will be listed here when a production deployment exists. This build is a development build; no public service is running.
